# Rooms — the 9 Korean concepts

Each room is a recurring concept in our voice. Each file documents:
- **Definition** (one line)
- **Etymology / origin** (one line)
- **When this room is the right room**
- **Three sample one-liners we'd actually post**
- **Anti-pattern** — what makes this room feel forced
- **Canonical receipt** — one fully-shaped post we keep ready

Use these when:
- Quality gate flags "no concept" but a concept fits
- A scaffold needs Korean-lens commentary
- A reply needs grounding in something specific

**Don't stack rooms in one post.** Pick one. Two, max, if they're sisters (가성비 + 깐깐함, 의리 + 한솥밥). Three is lecture mode.

| Room | Sister rooms | Tension with |
|---|---|---|

| 깐깐함 | 가성비, 정성 | 빨리빨리 |

| 의리 | 한솥밥 | 가성비 |
| 한솥밥 | 의리 | (none) |
| 危機 | (none) | 가성비 |
| 복기 | 깐깐함 | 빨리빨리 |
| 눈치 | 정성 | 빨리빨리 |
| 정성 | 깐깐함, 눈치 | 빨리빨리 |

The tension column is the most useful: a post that holds two opposing rooms in honest tension lands harder than a post that resolves one.
